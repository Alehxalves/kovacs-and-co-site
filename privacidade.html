Privacy Policy

Kovacs & Co · Last updated October 24, 2026

Kovacs & Co is a personal tool run by one person on their own computer to publish videos to their own YouTube channel. It has no other users.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Data accessed

With the account holder's consent, the tool requests these Google OAuth scopes:

  • youtube.force-ssl: to upload, schedule and update videos, thumbnails and captions on the authorized channel, and to read that channel's basic information.
  • yt-analytics.readonly: to read analytics reports for the authorized channel.

How data is used and stored

  • Data is used only to publish the owner's videos and to review how they perform.
  • The OAuth token and any analytics data are stored only on the owner's computer. Nothing is sent to servers run by this tool, because there are none.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time in Google Account permissions or through Google security settings. Deleting the local token file removes the stored credentials. To ask about stored data, write to the contact below.
